## What I Learned

- How to define a function that returns a value (`int check_lock(...)`) instead of `void`
- How to use `1` and `0` as simple true/false return values in C
- How to call a function directly inside an `if` condition (`if (check_lock(password) == 1)`)
- How separating the validation logic into its own function makes the code easier to read and test
